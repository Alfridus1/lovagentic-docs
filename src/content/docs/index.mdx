## Install

```bash
npm install -g lovagentic
lovagentic doctor --self-heal
```

`--self-heal` auto-imports your Lovable desktop session into the CLI profile so you don't need to log in twice.

## First prompt

```bash
lovagentic create --prompt "Simple todo app with dark mode" --name todos
lovagentic publish --id <project-id>
```

That's it. Thirty seconds to a live URL.
